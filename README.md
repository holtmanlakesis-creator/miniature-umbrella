# Freezio — Free IP Lookup Application

**Freezio** is a lightweight, fast, and completely free IP Lookup application for Android.  
**No money. No ads. No tracking.**

---

## 📥 How to Download & Install

### Option 1: Direct APK Download (Easiest)
1. Go to the **[Releases Page](https://github.com)**.
2. Tap **`Freezio.apk`** under **Assets** to download.
3. Open the downloaded file and allow **"Install from unknown sources"** if prompted by Android.

### Option 2: Automatic Updates via Obtainium
1. Install **[Obtainium](https://github.com)** on your Android device.
2. Tap **Add App** and paste this repository link:
   ```text
   https://github.com
   ```
3. Tap **Add** to install Freezio and receive automatic notifications whenever a new version is released.
